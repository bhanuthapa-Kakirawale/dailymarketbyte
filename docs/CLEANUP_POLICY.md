# Cleanup policy

```
python scripts\clean_dev_artifacts.py             DRY RUN - lists what would be deleted
python scripts\clean_dev_artifacts.py --verbose   ... every file, plus every protected match
python scripts\clean_dev_artifacts.py --execute   delete exactly that list
```

The rules live in `operations/dev_cleanup.py` and are tested (`tests/test_operator_tools.py`).
**If unsure, keep.**

## May be deleted (reproducible, generated, no historical value)

| Rule | What |
|---|---|
| PYTHON_CACHE | `__pycache__/` (outside venv/.venv/.git) and `.pytest_cache/`: regenerated automatically |
| OUTPUT_TEMP | Four files at the `output/` root: `bg_music_*.wav` (legacy music cache; V2 is silent), `nifty_chart_*.png` (legacy chart layers), the superseded `daily_market_byte_redesign_*.mp4`, and the `output/frames/` images |
| DEMO_RENDER | `output/daily_byte_*_DEMO.mp4`: synthetic data by definition |
| REVIEW_MEDIA | MP4 / PNG / JPG / GIF / WAV inside superseded review-render folders (hook_phase1*, hook_previews*, redesign, post_phase3, post_validation, post_freeze_validation, post_final_edge_cases, pre_phase1, redesign_audit, state_handoff_sim/runnerB). Their JSON / DB / CSV / MD / TXT / LOG evidence is **kept**. |

## Never deleted automatically

- `.env*`, `token.json`, `client_secret.json`, `venv/`, `.venv/`, `.git/`, `.claude/`
- source, tests, test fixtures, docs, `data/`, `assets/`: nothing outside `output/` except caches
- any `*.db`, `*.db-wal`, `*.db-shm`, `*.sqlite*`, wherever it is
- `output/data` (history, OHLCV, Radar candidate history, editorial selections)
- `output/reports` (canonical reports, including `unfit/` diagnostics)
- `output/radar` and **every `output/radar*` folder**: private intelligence, including rendered private charts
- `output/market_structure`, `output/official_snapshots`, `output/intelligence`, `output/exchange_watch`
- `output/publication`, `output/qa`, `output/report_jobs`, `output/post`: run audit trail
- `output/pre_shadow` and `output/premarket` (trial mornings)
- `output/private_radar` (private renders)
- `output/pre_shadow_readiness` (includes the stray-cleanup DB backup), `pre_production_readiness`,
  `pre_data_sources`, `benchmark_gap_recovery`, `session_alignment_validation`: live-data evidence
  that cannot be recreated
- `output/public_intelligence_v1`: the current approved V2 visual references
- `output/state_handoff_sim/store`: holds the real 25 Sep report, Radar and official snapshots
  from the two-runner simulation
- any file a non-demo run in the history database points at

## Regenerated by the pipeline

`output/post/<date>/freeze_frames`, the POST contact sheet, the MP4s of any day (re-render from the
canonical report with `python main.py --session-date <SESSION>`), the Python caches.

## Valuable state (back it up)

The databases in `output/data/`, `output/reports/`, `output/radar/`, `output/market_structure/`,
`output/official_snapshots/`, `output/intelligence/`. Together these are the canonical history
and the private intelligence. See docs/PRIVATE_INTELLIGENCE.md.
